# Yuchen (Julian) Li — Personal Website

Source for <https://julianli00.github.io/>, built with the open-source
[Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) Jekyll theme.

## Content

- English About page
- Resume covering education, experience, research, and skills
- Selected data science and NLP projects
- LinkedIn, GitHub, and email contact links

## Local development

```bash
bundle install
bundle exec jekyll serve
```

## Deployment

Pushes to `main` are built and deployed through GitHub Actions.
