# Yuchen (Julian) Li — Personal Website

Source for my English-language personal portfolio, built from the open-source
[vCard portfolio template](https://github.com/codewithsadee/vcard-personal-portfolio).

## Local preview

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>.

## Deployment

The site is static and can be published directly from the repository root with
GitHub Pages.
